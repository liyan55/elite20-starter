## 三、遇到的问题与解决

### 3.1 问题 1：Git 凭证设置
**问题描述**：第一次使用 Git，不知道如何配置 SSH 密钥

**解决过程**：
1. 查阅官方文档：https://docs.github.com/en/authentication/connecting-to-github-with-ssh
2. 生成了新的 SSH 密钥
3. 将公钥添加到 GitHub 账户
4. 测试连接：ssh -T git@github.com

**经验总结**：遇到问题先查官方文档，比搜索引擎更准确

### 3.2 问题 2：Markdown 格式不熟悉
**问题描述**：README.md 排版混乱，代码块无法高亮

**解决过程**：
1. 查阅 Markdown 语法指南
2. 学习使用 ```python 等代码块标记
3. 实践表格、列表等常用格式

**经验总结**：Markdown 是程序员的基本功，需要多加练习
