## 核心产物

### 四级作文批改标准

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 内容相关性 | 25% | 切题度、观点明确性 |
| 逻辑连贯性 | 25% | 段落衔接、逻辑严密性 |
| 词汇多样性 | 20% | 词汇丰富度、用词准确性 |
| 语法准确性 | 20% | 时态、语态、主谓一致 |
| 结构完整性 | 10% | 开头、主体、结尾 |

### 批改反馈示例

```
【作文批改报告】

总体评分：12/15 (80%)

✅ 优点：
1. 观点明确，能紧扣主题
2. 词汇量较丰富，使用了多个高级词汇
3. 段落结构清晰

⚠️ 需要改进：
1. 第三段逻辑衔接不够紧密
2. 部分句子存在语法错误（如时态不一致）
3. 结尾略显仓促，建议加强总结

📝 具体建议：
- 段落2：添加连接词 "Furthermore" 加强衔接
- 段落3：使用虚拟语气表达假设
- 结尾：可以使用 "In conclusion" 替代 "To sum up"
```

## 经验总结

### 作文批改原则
1. **评阅细致**：逐句分析，不放过任何语法和用词问题
2. **追踪过程**：记录学生的常见错误，建立个性化学习档案
3. **具体建议**：每条反馈都要有具体的修改方案
4. **正向引导**：在指出问题的同时，肯定学生的优点

### 思维模式转变
| 旧思维 | 新思维 |
|--------|--------|
| 一次性评分 | 持续追踪进步 |
| 笼统反馈 | 具体修改建议 |
| 单一评分 | 多维度分析 |
| 结果导向 | 过程+结果导向 |
